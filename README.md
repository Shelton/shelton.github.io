# sheltondavis.com

Personal site of Shelton Davis. One static page on GitHub Pages, no build step.

- `index.html` is the whole site
- `styles.css` is shared by `index.html` and `404.html`
- `CNAME` points the site at sheltondavis.com
- `.nojekyll` tells GitHub Pages to serve files as-is

To preview locally: `python3 -m http.server` and open http://localhost:8000.
